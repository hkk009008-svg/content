# docs/ navigation index

Find any document without listing every document. Nothing was moved to build
this index — series are addressed by their naming grammar, and the stats block
is regenerated by a committed instrument, never hand-edited:

```bash
env -u GIT_INDEX_FILE .venv/bin/python scripts/gen_doc_index.py
```

(`--check` verifies without writing; nonzero exit means a stale index.)

## 4. Historical series (address by grammar, don't browse)

| Series | Grammar | Retrieval |
|---|---|---|
| Handoffs | `HANDOFF-<seat>-<YYYY-MM-DD>-<slug>.md` | `ls docs/HANDOFF-coordinator-* \| tail -3` |
| Briefs | `BRIEF-*` | `ls docs/BRIEF-* \| tail -3` |
| Protocol bundles | `PROPOSAL-protocol-bundle-v*` / `REPLY-protocol-bundle-*` | highest version = latest |
| Audits | `AUDIT-*` | `ls docs/AUDIT-*` |
| Archive | `docs/archive/` (recursive) | superseded strata; do not cite as current |

rest, and none of them supersede the active singletons above.
